# 📊 Sales Dashboard – Power BI

An interactive **Sales Dashboard developed using Microsoft Power BI** to analyze sales, profit, quantity, orders, product categories, and customer segments.

## 📌 Project Overview

This project demonstrates how raw sales data can be transformed into meaningful business insights using **Power BI, Power Query, and DAX**.

The dashboard provides an interactive overview of sales performance through KPI cards, charts, tables, and category/segment analysis.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset
- Data Cleaning & Transformation
- Data Visualization

## 🔄 Data Preparation

The dataset was prepared using **Power Query**.

Main steps included:

1. Importing the CSV dataset into Power BI.
2. Cleaning the raw data.
3. Checking and correcting data types.
4. Formatting date columns.
5. Preparing numerical columns.
6. Creating DAX measures.
7. Building the required visualizations.
8. Designing the final interactive dashboard.

## 🧮 DAX Measures

```DAX
Total Sales = SUM(Sales[Sales])
````

```DAX
Total Profit = SUM(Sales[Profit])
```

```DAX
Total Quantity = SUM(Sales[Quantity])
```

```DAX
Total Orders = DISTINCTCOUNT(Sales[Order ID])
```
